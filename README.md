## 🛠️ Working with Data

The aladdin-spec system organizes information into reusable bundles. Professionals use these bundles to feed retrieval systems. Because the specification relies on open standards, you face no vendor lock-in. 

To create your first knowledge pack, open the application and select "New Project" from the main screen. You must define a schema, which acts as a blueprint for your data. Once you define the schema, you populate the pack with your information. The tool validates this information to ensure it meets the standard. If the software finds a mistake, it flags the specific field for your correction.

## 📋 Common Questions

**How does this interact with AI agents?**
The agents read the structured knowledge packs directly. Because the format is standardized, the agent understands the relationships between different pieces of data.

**Is my data private?**
The software runs locally on your machine. You control where you store the knowledge packs and who accesses them. 

**What if I have an existing data set?**
The import tool allows you to map existing CSV or JSON files into the spec format. You simply define the relationship between your existing headers and the specification requirements.

**Can I run this on a server?**
While this version is designed for Windows desktop users, the specification format remains compatible with server-based knowledge bases.
